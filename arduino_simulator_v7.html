    How to use

    1. Beginner mode opens a wired LED that is already blinking. Change 1000 to 200, then press Run. Advanced brings back wiring tools, the scope, and file exports.
    2. Drag from a pin or breadboard hole and drop on another to connect a wire. Holes in the same column (a–e or f–j) are tied together; power rails are separate. ⚡ Auto Wire seats parts and lands wires on the holes.
    3. Scroll to zoom the canvas. Drag empty space to pan. Press 100% to restore the view.
    4. Run the simulation with the green play icon (Ctrl+Enter). Drag the canvas and code edges to resize.
    5. Undo / Redo (Ctrl+Z, Ctrl+Y) restores components, wires, the board, and code.
    6. Click a button component, or hold Space to press it.
    7. Moving a sensor slider changes its value while the simulation is running.
    8. File → New Project opens LED Blink. Empty Project leaves only the Arduino board. If the current work has changed, you can keep it in Recent first. Save As names that copy. The panel layout stays as you left it.
    9. Run warns in the serial monitor when a pin has no wire, an LED has no resistor, or a part is on the wrong voltage. The baud rate is shown above the monitor. Pause, Copy, and Time leave the log in place. Clear is the only button that erases it.
    10. Your work is saved in the browser automatically. You can also download JSON, .ino, or a PNG (with or without the canvas background) from the File menu. Right-click the canvas for the same image options. A selection exports just those parts.

    Keep this project?

    Opening another project replaces the one on screen. You can keep this one in Recent.
